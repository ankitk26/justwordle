# justwordle

justwordle is a web-based word guessing game where players attempt to guess a word within a limited number of tries. Each guess provides color-coded feedback: green for correct letters in the correct position, yellow for correct letters in the wrong position, and gray for letters not in the word.

## Tech Stack

- **Runtime**: Bun
- **Framework**: React 19 with TypeScript
- **Routing**: TanStack Router
- **Data Fetching**: TanStack Query
- **Full-Stack**: TanStack Start
- **State Management**: Zustand
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn
- **Linting/Formatting**: Biome and Ultracite

## Development

### Prerequisites

Make sure you have [Bun](https://bun.sh) installed on your system.

### Installation

```bash
bun install
```

### Running Locally

Start the development server:

```bash
bun run dev
```

The application will be available at `http://localhost:3000`.

### Build

Build the application for production:

```bash
bun run build
```
